The user is **Than Grove**, the original developer (repo created 2019-07-31) of the Tibetan &
Himalayan Library (THL) Tibetan text processing scripts. He converts and marks up Tibetan texts
(notably the Peltsek Kama volumes): Sambhota→Unicode conversion, milestone insertion, THL style
application. Finished volumes are posted to Teams.

He is comfortable with Python and git, works hands-on with the code, and reviews changes closely
(e.g. once corrected a wrong assumption about the current git branch). He works on more than one
computer against this same repo, which is why memory lives in `.claude/memory/` and context in
`SESSION_LOG.md` (see [[feedback-memory-location]], [[session-log-convention]]).
